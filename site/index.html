Add the repositories

On an XCP-ng 8.3 host, as root:

curl -o /etc/yum.repos.d/xcp-hl.repo https://rpm.xcp-hl.org/xcp-hl.repo
rpm --import https://rpm.xcp-hl.org/xcp-ng-ce-public.asc
yum clean all && yum install xcp-hl-release

Installing xcp-hl-release replaces the bootstrap file with the packaged copy, after which repository configuration is managed by yum.

Verification

Each repodata/repomd.xml carries a detached armored signature, checked by repo_gpgcheck=1. The signed repomd.xml records a SHA-256 of primary.xml, which records a SHA-256 of every package. Per-package checking is off (gpgcheck=0) on purpose: rpm 4.11 on XCP-ng 8.3 dom0 cannot verify signatures made by a signing subkey.
